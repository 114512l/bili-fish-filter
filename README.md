# 大肥鱼\~一网打尽！

B站 评论区过滤器。识别疑似 AI 养鱼评论，折叠成「该内容已被折叠」占位条，顶部面板可展开、定位、一键重折。

不是按名字杀——名字带「大肥鱼」只算 1.4 分辅助，单独出现不会触发。

\---

## 功能

* 拦截 B站 评论接口拿结构化数据（等级 / mid / 正文 / rpid）
* 按规则打分，超过阈值（默认 4.5）就折叠；
* 原位置插入「该内容已被折叠 · 展开」，点开恢复原文并记住选择；
* 主评论折叠时，楼中楼一起收起；
* 顶部面板：已折叠数量、逐条命中原因、定位、全部折叠、阈值与开关；
* 切换「最新 / 最热」或页面重渲染后，自动重新折叠。

## 实现

1. `manifest.json` 用 `world: "MAIN"`，在 `document\_start` 挂 `fetch` / `XMLHttpRequest` 钩子，匹配 `/x/v2/reply`；
2. 从响应里取 `data.replies` / `top\_replies` 逐条打分，结果存在 `allComments`；
3. 按当前阈值生成折叠列表，卡片定位穿透 Shadow DOM（`bili-comment-renderer`）；
4. 折叠为占位条 + 隐藏卡片；`MutationObserver` + 600ms 节流轮询处理懒加载与翻页；
5. 阈值与开关存本机 `localStorage`。

\---

## 安装

1. 把 `bili-fish-filter` 文件夹放到固定位置；
2. 浏览器打开 `edge://extensions`（或 `chrome://extensions`），开启「开发者模式」；
3. 点「加载已解压的扩展程序」，选这个文件夹；
4. 打开任意 B 站视频页，刷新评论区。

要求 Chrome / Edge **111+**。

## 打分规则

总分 ≥ 阈值（默认 4.5）即折叠：

|规则|加分|
|-|-|
|等级 L0/L1|+3|
|等级 L2|+2.4|
|等级 L3|+1|
|以 `@` 开头|+1|
|正文 > 40 字|+1|
|正文 > 100 字|再 +0.5|
|名字含「大肥鱼/小肥鱼/鲸鲸/小鲸鱼/鲸娘」|+1.4（辅助）|
|长文里出现「大肥鱼」（落款/自称）|+1.5|
|命中模板词，每个 +1.2，封顶 +4（长串优先去重）|—|

主观效果，未做严格评测

## 面板与交互

评论区顶部显示：

```
🐟 大肥鱼\~一网打尽！ · 已折叠 3 条     全部折叠   展开
```

* 每条列出用户名、等级、mid、分数、命中原因、正文；
* 「定位」：滚动到原评论位置（短暂蓝框高亮），不展开；
* 「全部折叠」：把手动展开过的评论全部重新折叠；
* 「阈值」：1～10，实时生效（已加载的评论会按新阈值重新过滤）；
* 「隐藏原评论」：开 / 关折叠占位。

\---

## 限制

* 只处理当前已加载的评论，不主动抓全量；
* 只折叠自己看到的，不改变别人看到的评论区；
* B站 评论区结构改动时需要更新选择器；
* 楼中楼异步渲染的节点可能漏藏，下次扫描补。
